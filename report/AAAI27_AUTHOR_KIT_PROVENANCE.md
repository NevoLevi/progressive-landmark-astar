# AAAI 2027 author-kit provenance

The course instructions recommend the AAAI'27 camera-ready format while
allowing other formats. On 2026-08-11, the official course URL
<https://aaai.org/authorkit27/> redirected to the official AAAI archive:

<https://aaai.org/wp-content/uploads/2026/05/AuthorKit27.zip>

The downloaded ZIP had SHA-256
`E28C6AC9BC6EB3B4E2D849547D2CEFB5162610EE39D0A12E0DC62D1126B44A7D`.
The two assets copied unchanged into the private working directory are:

- `aaai2027.sty`: `391BCE82815BF698B8E382DD3AE7E30C75D7AB46DF140CB295B1266016BC8623`
- `aaai2027.bst`: `5DB7765BA99DE5C1E4686F9B3940A0ADD9C5E702F2164514462BEC130CCB6E3C`

The public project artifact intentionally omits `aaai2027.sty`. AAAI's
[copyright notice](https://aaai.org/about-aaai/copyright-notice/) does not grant
permission to republish website materials on a public repository. To rebuild
the paper, download the official kit above, verify the archive and style hashes,
and copy the unmodified style beside `main.tex`. The included `aaai2027.bst`
states its LaTeX Project Public License terms in its own header.

AAAI's proceedings instructions normally prohibit `\nocopyright`. This is a
course report rather than an AAAI proceedings submission, and the current
course instructions specifically recommend using `\nocopyright`; the report
therefore follows the course-specific instruction.
